# TypeQuest frontend

React 19 + Vite 8. The full documentation, including how every folder in `src/` works, is in the
[main README](../README.md#8-frontend-piece-by-piece).

```bash
cp .env.example .env    # set VITE_API_BASE_URL (and VITE_CONTACT_EMAIL for production)
npm install
npm run dev             # http://localhost:5173
npm run lint
npm run build           # output in dist/
```
